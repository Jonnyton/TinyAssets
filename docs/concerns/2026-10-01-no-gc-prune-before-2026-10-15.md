# Do not run `git gc --prune=now` in the TinyAssets repo before 2026-10-15

**Filed:** 2026-10-01. **Delete this file after 2026-10-15.**

On 2026-10-01, 249 worktrees were preserved and then removed by hand to reclaim
23.2 GB. Each one's working-tree state was preserved on a local-only ref,
`refs/preserved/<name>-20261001`. That manual pass started its snapshot from HEAD,
not from the worktree's own index. So where a lane's index held staged content
that differed from both HEAD and the working file, that content is in no ref. It
exists only as unreachable loose objects in the primary repository's object
store.

Those blobs can be recovered with `git fsck --unreachable` (or `--lost-found`)
until gc prunes them. The default `gc.pruneExpire` is two weeks, so after
2026-10-15 an ordinary `git gc` may delete them anyway. Until then, do not
shorten that window with `git gc --prune=now`, `git prune`, or
`git reflog expire --expire-unreachable=now`.

The scripted path in `scripts/dev_hygiene.py` (PR #4186) does not have this gap.
It adds the real index as a second parent of the snapshot commit. The removal log
is `C:/Users/Jonathan/Projects/ta-preserved/REMOVALS-20261001.md` on the dev box.
