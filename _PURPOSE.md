# Purpose
Separate users at the tool boundary, without changing how a universe's brain learns:
another user's content (commons shapes, listings, foreign branches, run output) reaches the
served universe inside an untrusted envelope, the persona prompt names it, and orgchart.md is
read back founder-privately. Founder 2026-08-29: "it's a separating-users architectural
issue, not a change in how the brains for each user works."
